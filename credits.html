Credits

Frostforge is made by the Frostforge developer, Anderson Fantin. Third-party material used in the game:

  • Kenney (CC0 1.0, https://kenney.nl): 3D models, UI skin, icons, fonts and sounds (Factory Kit, City Kit Industrial, Survival Kit, Castle Kit, Space Kit, UI Pack, Game Icons, Fonts, Toon Characters, UI Audio, Interface Sounds, Impact Sounds, RPG Audio, Music Jingles).
  • game-icons.net (CC BY 3.0, https://game-icons.net): item icons made by Lorc (http://lorcblog.blogspot.com) and Delapouite (https://delapouite.com).
  • Roboto (SIL Open Font License 1.1): main text font, https://github.com/googlefonts/roboto-3-classic.
  • Music and ambience: any track by a CC BY artist is credited in the game (Menu, About, Credits).

Everything else (app icon, procedural meshes, shaders) is original. The same list is in the game: Menu, About, Credits.
